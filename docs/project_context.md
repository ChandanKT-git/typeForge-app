# TypeForge: Project Context

**TypeForge** is a premium, AI-powered typing platform designed to help users improve their typing speed and accuracy through dynamic, focused practice sessions and intelligent analytics. It draws inspiration from tools like Monkeytype, blending a distraction-free "Flow State" typing arena with high-end, "Terminal Luxury" analytics dashboards.

## 1. Technologies Used

### Backend Stack
*   **Framework:** [FastAPI](https://fastapi.tiangolo.com/) (Python 3) for high-performance, asynchronous REST APIs.
*   **Database:** MongoDB with [Motor AsyncIO](https://motor.readthedocs.io/en/stable/) for non-blocking database operations.
*   **Authentication:** Stateless JWT using `pyjwt`, `bcrypt` via `passlib`, and `requests-oauthlib`.
*   **Data Validation:** [Pydantic v2](https://docs.pydantic.dev/) for strict request/response serialization.
*   **AI Integrations:** `groq` for AI-based text generation and mistake analysis, plus `boto3` for AWS services.
*   **Tooling:** Pytest, Black, Isort, Flake8, and Mypy for testing and code quality.

### Frontend Stack
*   **Framework:** React 19 bootstrapped with Create React App (using `@craco/craco` to override configurations).
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) with a strict dark-mode-only configuration.
*   **UI Primitives & Components:** Radix UI primitives heavily utilized (via shadcn/ui patterns) for accessible, unstyled UI components (Dialog, Tabs, Toast, Hover Cards).
*   **Icons & Typography:** [Lucide React](https://lucide.dev/) for iconography. Fonts include `IBM Plex Mono` (for the typing arena) and `Inter` (for general UI).
*   **Forms & Validation:** `react-hook-form` paired with `zod` for robust client-side validation.
*   **Data Visualization:** [Recharts](https://recharts.org/) for rendering post-session analytics and dashboard statistics.
*   **Animations:** `tailwindcss-animate` and Framer Motion patterns for fluid caret movement and page transitions.

## 2. Design Philosophy & Guidelines

The project strictly follows a **"Terminal Luxury"** aesthetic defined in `design_guidelines.json`:
*   **Colors:** Deepest black backgrounds (`#09090B` or Tailwind's `zinc-950`) instead of pure black, with glassmorphic (`zinc-900/50` + `backdrop-blur`) panels. Primary accents use a vibrant blue (`#3B82F6`).
*   **Typing Arena:** Maximum focus. No distractions. The typing caret glides smoothly character-by-character. Correct letters are bright white, incorrect are rose (`#F43F5E`), and untyped are muted zinc (`#71717A`).
*   **Analytics:** Post-session data is presented like a high-end fintech dashboard, prioritizing density, clarity, and dark-mode styling without intrusive grid lines.

## 3. Code Patterns & Architecture

### Backend Patterns
*   **Modular Routers:** The API is cleanly divided into domains using FastAPI's `APIRouter`.
    *   `auth.py`: Handles JWT token issuance and user registration/login.
    *   `sessions_router.py`: Manages the storage of typing test results (WPM, accuracy, keystroke data), session history, streaks, and dynamically generates difficulty recommendations.
    *   `topics_router.py` & `ai_service.py`: Handle generating target texts and providing AI-based mistake analysis.
*   **Dependency Injection:** Shared resources like the MongoDB database instance (`request.app.state.db`) and the current user (`Depends(get_current_user)`) are injected directly into endpoint handlers.
*   **Data Aggregation:** Endpoints like `/sessions/stats/overview` calculate moving averages, WPM streaks, and aggregate data natively in Python logic over recent records.

### Frontend Patterns
*   **Page-Based Routing:** Located in `src/pages/` (e.g., `Dashboard.jsx`, `Practice.jsx`, `Results.jsx`, `History.jsx`).
*   **Protected Routes:** A `ProtectedRoute.jsx` component wraps authenticated views, ensuring users are redirected to `/login` if not authenticated.
*   **UI Component Library:** Reusable components are housed in `src/components/ui/` (likely generated by shadcn/ui), ensuring consistent styling and accessibility across forms, modals, and buttons.
*   **State Management:** Local component state handles real-time typing logic inside `TypingArena.jsx`, tracking keystrokes, calculating live WPM/accuracy, and handling the active caret position.

## 4. Key Workflows
1.  **Session Lifecycle:** A user navigates to the Practice page, selects a topic/difficulty (or accepts an AI recommendation), and begins typing. The `TypingArena` component tracks every keystroke (time and correctness).
2.  **Completion & Results:** Once the target text is completed, the frontend submits a complex payload to `POST /api/sessions`. The user is immediately redirected to the Results page, which fetches the AI analysis and renders Recharts graphs of their session trajectory.
3.  **Progression:** The backend analyzes the last 5 sessions to recommend moving up/down in difficulty (Beginner, Intermediate, Advanced) based on an accuracy threshold (e.g., >= 95% accuracy promotes difficulty).
